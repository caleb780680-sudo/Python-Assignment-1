## 📝 Tasks Included

### 🔹 Task 1: String Concatenation

This task demonstrates how to combine strings using the `+` operator.

The program:

* Takes the user's name as input
* Combines `"Hello "` with the name
* Adds a welcome message
* Displays the final string

Example:

```python
string1 = "Hello "
name = input("Enter your Name: ")
concatenated_string = string1 + name
```

---

### 🔹 Task 2: String Slicing and Indexing

This task demonstrates different ways to access and extract characters from a string.

Operations include:

* Printing the first character
* Printing the last character
* Extracting the first 5 characters
* Extracting the last 11 characters
* Reversing the string
* Extracting the word `"Python"`

Example:

```python
text[0]
text[-1]
text[:5]
text[-11:]
text[::-1]
```

The assignment also uses `find()` to locate `"Python"` before extracting it.

---

### 🔹 Task 3: String Methods

This task demonstrates commonly used Python string methods.

Methods covered:

| Method          | Purpose                           |
| --------------- | --------------------------------- |
| `.upper()`      | Converts text to uppercase        |
| `.lower()`      | Converts text to lowercase        |
| `.capitalize()` | Capitalizes the first character   |
| `.count()`      | Counts occurrences of a character |
| `.replace()`    | Replaces specified text           |

Example:

```python
strM = "Python beginner tutorial."

print(strM.upper())
print(strM.lower())
print(strM.capitalize())
print(strM.count("t"))
```

The assignment also replaces `"Python"` with `"Data Analytics"` using `replace()`.

---

### 🔹 Task 4: Tuple Operations

This task demonstrates basic operations on Python tuples.

Two tuples are created:

```python
tuple1 = (10, 20, 30)
tuple2 = (40, 50, 60)
```

Operations performed include:

* Concatenating two tuples
* Repeating tuple elements
* Accessing the third element
* Extracting the first three elements
* Extracting the last three elements

Example:

```python
t_combine = tuple1 + tuple2
t_repeated = t_combine * 3
```
